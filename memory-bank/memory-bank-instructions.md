# Memory Bank Instructions

The Memory Bank serves as the cornerstone for documenting the essential components of our project. It helps maintain clarity and organization within the project lifecycle. Ensure to update the bank with new findings, project context, and patterns as they emerge.

## Workflow
1. **Documentation**: Maintain updated files related to the project brief, contexts, and patterns.
2. **Consistency**: Ensure all entries are coherent and aligned with the current project state.
3. **Review**: Regularly assess the contents for relevance and accuracy.

For additional instructions, refer to the detailed guidelines in `.github/instructions/memory-bank.instructions.md`.
