BUILDING TYPES SUPPORTED
================================================================================

1. civic - Town halls, government buildings
2. commercial - General stores, markets
3. social - Gathering places
4. crafting - Workshops, forges
5. agricultural - Farms, barns
6. educational - Schools, learning centers
7. residential - Houses, homes
8. office - Administrative buildings
9. tavern - Inns, taverns (alias for social)
10. shop - Specialized shops (alias for commercial)
11. workshop - Specialized workshops (alias for crafting)
12. farm - Farms (alias for agricultural)
13. school - Schools (alias for educational)
14. library - Libraries (special educational)
15. house - Houses (alias for residential)

Each type has 1-4 unique interactions with preconditions and effects.

================================================================================
ERROR HANDLING
================================================================================

The system gracefully handles:
- Missing files → empty list + warning
- Invalid JSON → empty list + error  
- Missing required fields → skip building + warning
- Invalid numeric values → use defaults + warning
- Unrecognized types → keep type + info message
- Malformed structure → empty list + error
- Empty buildings array → empty list + info

================================================================================
USAGE EXAMPLE
================================================================================

Config file (custom_buildings.json):
{
  "buildings": [
    {
      "name": "Village Inn",
      "type": "tavern",
      "x": 300,
      "y": 200,
      "width": 50,
      "height": 48,
      "description": "A cozy inn"
    }
  ]
}

Loading in code:
config = {
    "map": {
        "buildings_file": "custom_buildings.json"
    }
}
controller = GameplayController(config=config)

Result:
✅ Building loaded with:
   - Correct position (300, 200)
   - Correct size (50x48)
   - 4 tavern interactions (Enter, Socialize, Get Drink, Join Activity)
   - All preconditions and effects configured
